Privacy policy

The short version: glancecard has no account, no telemetry and no analytics. It reads GitHub's API and writes SVG files to your repository. This website sets no cookies.

The glancecard action and CLI

  • It runs where you run it: in your own GitHub Actions workflow, or on your machine. Nothing reaches us.
  • GitHub's API (api.github.com). Everything on a card is read from it, with the token you give it: the workflow's own by default. It only reads from GitHub; the one thing it writes is the commit of the cards to the repository the workflow runs in.
  • Avatars (avatars.githubusercontent.com). The pictures of the profile and of a repository's contributors are downloaded and embedded in the cards.
  • What a card shows is public by default: with the workflow's token, what anyone can see. Private repositories are refused unless you set allow-private, because their card would publish their activity wherever it is committed.
  • No telemetry, no analytics and no crash reports. The token stays in memory and is never written anywhere.

This website

  • No cookies, no analytics, no cross-site tracking, and nothing kept in your browser's storage.
  • Hosting. The site is served by GitHub Pages. Like any host, GitHub processes your IP address and the details of each request to deliver the pages and keep them secure. We have no access to those logs; GitHub keeps them under its own privacy statement.
  • Everything the page shows is served by the site itself, the cards included: no fonts, scripts or pictures are loaded from anywhere else.
  • Email. If you write to us, we use your address and message only to answer you, and keep them no longer than the conversation needs.
  • Links. GitHub, the GitHub Marketplace, GitHub Sponsors and FinderGit are services of their own, and nothing is loaded from them until you click. If you use them, their own privacy policies apply.
